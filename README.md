# BrokerFlow AI

BrokerFlow AI is a modern full-stack AI-powered SaaS web application for real estate brokers to manage leads and automate WhatsApp conversations.

## Architecture

- **Frontend**: React + Vite + Tailwind CSS (Beige & Dark Brown Theme)
- **Backend**: Node.js + Express
- **Database**: Supabase / PostgreSQL (Integration Placeholder)

## Quick Start

### 1. Backend Setup

```bash
cd backend
npm install
npm run dev
```
The backend will run on `http://localhost:5000`. Make sure to copy `.env.example` to `.env` and fill in your Supabase and WhatsApp credentials when ready.

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
The frontend will run on `http://localhost:5173`.

## Features
- Dashboard with Analytics
- AI WhatsApp Chat Interface
- Leads Management & AI Lead Scoring
- Property Inventory
- Site Visits Calendar
- Automation Settings
